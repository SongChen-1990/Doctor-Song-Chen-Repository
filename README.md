# VTE Bioinformatics Analysis Code

This repository contains the analysis code for the manuscript: 
**"Immune-related hub genes and disturbed immune infiltration in venous thromboembolism: from bioinformatics to clinical validation"**

## Overview
This project includes the R scripts used for the bioinformatics analysis in the study. The code covers the following main steps:
- Data preprocessing and normalization
- Identification of differentially expressed genes (DEGs)
- Functional enrichment analysis (GO and KEGG)
- Immune infiltration analysis (CIBERSORT)
- Construction of the protein-protein interaction (PPI) network and hub gene identification
- Machine learning model construction and validation (LASSO, Random Forest, etc.)
